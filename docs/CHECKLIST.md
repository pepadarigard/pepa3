# Проверка на своём ПК

Всё, что зависит от настоящих программ — AdsPower, Telegram, окна Windows, перехват мыши и клавиатуры, само окно
Pepa, — проверено в разработке только на имитациях (см. [TESTING.md](TESTING.md)). Здесь — что проверить у себя, по
порядку: от простого к сложному. Каждый пункт — несколько минут.

Если что-то пошло не так, пришлите:
- что делали и что ожидали;
- снимок страницы процесса (вкладки «Шаги» и «Журнал»);
- последний файл журнала из `%LOCALAPPDATA%\Pepa\logs\`.

Ключей, паролей и кодов в журнале нет. Перед отправкой всё же посмотрите, нет ли там того, чем не хотите делиться
(например, текстов сообщений).

## 1. Окно Pepa

1. Запустите `Pepa.exe`: откроется окно с «Главной». Появятся одиннадцать примеров.
2. Запустите `Pepa.exe` ещё раз — второе окно не откроется, вперёд выйдет уже открытое.
3. Запустите «Пример 3» (ждёт 15 секунд) и закройте окно. Pepa предупредит, что процесс работает. Откройте Pepa снова:
   процесс приостановлен и продолжится только кнопкой «Продолжить».
4. «Настройки» → «Рабочая папка» → выбрать папку и «Открыть в проводнике».

## 2. Браузер

1. «Пример 7»: откроется Edge, заголовок страницы сохранится в переменную.
2. Конструктор → «Записать» → «В браузере» → начать с любого сайта → нажмите пару ссылок, введите текст в поиск →
   «Остановить и добавить в сценарий». Блоки должны появиться на схеме. Запустите их — действия повторятся.

## 3. AdsPower

1. Запустите AdsPower и проверьте, что в его настройках включён Local API (AdsPower: «Настройки» → «Local API»; адрес
   обычно `http://127.0.0.1:50325` — такой стоит в Pepa по умолчанию).
2. Pepa: «Настройки» → «AdsPower» → «Проверить связь» — должен появиться список профилей.
3. «Пример 8»: выберите профиль. Профиль откроется, Pepa сделает снимок страницы и будет ждать событие-ответ (его
   можно отправить на странице «Выполнение» → «Отправить событие»).
4. Запустите «Пример 8» два раза подряд с одним профилем. Второй процесс должен ждать, пока профиль освободится, а не
   открывать его второй раз.

## 4. Telegram

1. «Интеграции» → Telegram: api_id и api_hash (my.telegram.org → API development tools), телефон, код. Если Telegram
   в сети недоступен — там же «Прокси».
2. «Пример 9»: укажите чат (например, свой второй аккаунт или знакомого), процесс отправит вопрос и будет ждать
   ответ. Ответьте — процесс получит ответ и закончится.
3. То же, но после отправки закройте Pepa, ответьте в Telegram и откройте Pepa снова. Процесс приостановлен. После
   «Продолжить» он получит ответ, пришедший, пока Pepa была закрыта.
4. Кнопки бота: блок «Нажать кнопку в Telegram» на сообщении бота, у которого нажатие ничего не меняет (например, переключение
   страниц справки). Кнопка нажимается один раз. Если связь прервалась во время нажатия, Pepa не нажимает
   повторно, а спрашивает вас.
5. «Пример 10» — всё вместе: профиль AdsPower, сайт, сообщение и ответ.
6. «Настройки» → «Уведомления» → включить, «Сохранить», «Отправить пробное сообщение» — оно придёт в «Избранное». Потом
   запустите сценарий, который остановится (например, «Записать файл» в недопустимый путь): придёт одно сообщение, а
   свёрнутое окно Pepa замигает на панели задач.

## 5. Окна Windows

1. Новый сценарий:
   - «Запустить программу» `notepad.exe`;
   - «Ввести в окне»: окно «Блокнот», поле — кнопкой «Выбрать элемент в окне» (Блокнот должен быть открыт), текст —
     любой;
   - «Прочитать из окна» из того же поля.

   Запустите: текст появится в Блокноте, а прочитанный совпадёт.
2. «Выбрать элемент в окне» для Калькулятора (приложение из Microsoft Store): кнопки цифр должны быть с пометкой
   «уникальный код». Сценарий «нажать 2, +, 3, =» и «Прочитать из окна» результат.
3. Откройте в Блокноте «Файл» → «Сохранить как» и запустите блок «Нажать в окне» по главному окну Блокнота, пока открыт
   диалог. Pepa не должна печатать или нажимать в главное окно мимо диалога. Если окно-диалог выходит вперёд, а не
   главное окно, — хорошо. Если нет — пришлите журнал.
4. Таблица: в программе с таблицей (например, Excel или любая с таблицей настроек) введите текст в ячейку блоком
   «Ввести в окне», способ «Клавиатурой, по символам». Ввод в поле правки ячейки должен пройти. Если Pepa остановилась со
   словами «фокус перешёл на другое поле», пришлите журнал.
5. Программа, запущенная от имени администратора: Pepa без прав администратора ввод в неё не пропустит и скажет
   почему. Это ожидаемо. Если запустить Pepa от имени администратора, расширения не загрузятся — тоже ожидаемо, причина
   видна в «Настройках».

## 6. Запись в окнах Windows

1. Конструктор → «Записать» → «В окнах Windows» → «Начать запись».
2. В Блокноте: нажмите в поле текста, напечатайте строку с исправлением (Backspace), нажмите Ctrl+S, в диалоге введите
   имя файла и нажмите «Сохранить».
3. Вернитесь в Pepa → «Остановить и добавить в сценарий». Шагов должно быть немного:
   - «Ввести в окне» с итоговым текстом, а не с каждой буквой;
   - «Клавиши Ctrl+S»;
   - ввод имени файла;
   - «Нажать «Сохранить»».

   У ненадёжных шагов есть пояснение.
4. Закройте Блокнот без сохранения и запустите записанные блоки — действия повторятся.
5. Отдельно проверьте контекстное меню (правая кнопка → пункт меню) и выпадающий список. Это самые трудные места.
   Опишите, что записалось и что получилось при запуске.

## 7. ИИ-помощник (если нужен)

1. «Настройки» → «ИИ-помощник» → ключ API Anthropic → «Проверить».
2. Конструктор → «ИИ-помощник» → «Новые блоки»: опишите задачу словами. Затем «Изменить сценарий» и «Объяснить
   сценарий».
3. Изменения видны до применения и отменяются Ctrl+Z.

## 8. Свои блоки (для разработчиков)

Соберите `samples/Pepa.Plugins.Sample` и положите `Pepa.Plugins.Sample.dll` в
`%LOCALAPPDATA%\Pepa\plugins\sample\`, перезапустите Pepa. В «Настройках» → «Расширения» должен появиться пример, а в
палитре — раздел «Пример расширения».

## 9. Резервные копии

1. «Настройки» → «Резервные копии»: после первого запуска там уже есть ежедневная копия. «Сделать копию сейчас» — появится
   ещё одна, «Открыть папку» — папка с копиями.
2. Проверка восстановления (необязательно): запустите «Пример 3» (ждёт 15 секунд), сразу сделайте копию, дождитесь конца
   процесса и закройте Pepa. Замените `pepa.db` копией, как написано в «Как восстановить из копии», и запустите Pepa.
   Процесс должен стоять с пояснением «База восстановлена из копии» и сам не продолжаться.

# Тестирование

Надёжность проверяется автоматическими тестами поведения, а не ручным запуском. Внешние сервисы заменяются
имитациями там, где это позволяет проверить логику без реальных действий.

## Уровни

| Уровень | Где | Что проверяет |

### Инструменты имитации

- `ExternalWorld` + `TestActionNode` — внешнее действие с управляемым поведением: успех, подтверждённая ошибка,
  исключение до/после эффекта, остановка внутри действия до команды теста, принудительный итог проверки.
  Считает и вызовы, и фактические эффекты — отдельно.
- `FaultInjectingStore` — обёртка хранилища, которая «роняет» запись в заданный момент (например, при записи
  «подтверждено» для конкретного шага), а затем — все последующие записи (жёсткий сбой).
- `EngineHarness` — движок над временной базой; «перезапуск» и «аварийный перезапуск» создают новый движок над
  тем же файлом.

Браузер и AdsPower (`Pepa.Adapters.Browser.Tests`) проверяются на настоящем Chromium и маленьком тестовом сайте:
открыть, ввести, нажать с проверкой, прочитать, снимок, закрыть; отсутствующий и неоднозначный элемент не
нажимается; потерянный после перезапуска браузер сообщается. AdsPower — на имитации Local API, которая, как
настоящий AdsPower, запускает браузер с портом отладки: открытие и закрытие профиля, ключ API, запасной v1,
пауза между запросами, второй процесс ждёт профиль, переподключение после перезапуска без повторного открытия,
закрытый пользователем профиль. Браузер для тестов: `PEPA_TEST_BROWSER_PATH` или `PEPA_TEST_BROWSER_CHANNEL`
(в CI — Edge на Windows и Chrome на Linux); без браузера эти тесты пропускаются.

Вопросы пользователю (`Pepa.Engine.Tests/QuestionTests`, `Pepa.Host.Tests/QuestionApiTests`,
`AttentionNotifierTests.Question_*`) — вопрос с вариантами ждёт одного ответа (второй — «уже ответили», не из
вариантов — отказ), подстановки в вопросе; свой ответ и секретный ответ: в переменной настоящий (с пробелами), в
журнале, итоге, событии и при показе шагов — скрыт; ответ в секретную переменную — секрет; без ответа — «Тайм-аут», а
поздний ответ отклоняется; вопрос переживает перезапуск, ответ применяется после «Продолжить»; ответ нельзя подделать
ни «Отправить событие», ни API событий, ни перехватить «Ждать событие». В API: список без секретов, ответ номером
варианта один раз, картинка из рабочей папки только как картинка и не из-за её пределов. Уведомление: о вопросе — один
раз, с текстом, о заданных до запуска — нет, новый вопрос того же процесса — снова. Пример 14: два ответа
через API — отчёт создан. D-062: после срока (и пока процесс на паузе) вопрос не показывается и ответ не принимается;
ответ не достаётся автозапуску (автозапуск на `pepa.question` не сохраняется), а вернувшийся к сопоставлению — не
отдаётся вручную чужому вопросу; вариант из секретной переменной — секрет события; ответ в переменную-число
разбирается («42,5»), не число — отказ с открытым вопросом; варианты, получившиеся пустыми, — ошибка шага; повторный
ответ после доставки — «уже ответили»; уведомления по номеру вопроса (тот же текст снова — новость, пауза — нет,
вопрос при работающей ветви — новость). D-063: секретный ответ в переменную-число скрыт везде, код с нулём в начале,
NaN и бесконечность не принимаются; варианты, не подходящие к типу переменной, — ошибка шага; остановка и второй вопрос
в одной пачке — обе новости, сбой чтения вопросов не даёт повторного сообщения. Сквозная проверка: вопрос на «Главной», ответ кнопкой, процесс завершён с этим ответом.

Таблицы (`Pepa.Adapters.Tables.Tests`) — книга как из Excel (общие строки, форматы даты и денег, формула, второй лист,
«умная таблица»): строки по названиям колонок, числа, даты текстом ISO, результат формулы, колонка без названия — буквой,
другой лист по имени, без строки названий — буквы. «Добавить»: оформление из строки выше, текст с «=» — текст, формулы и
другие листы на месте, «умная таблица» и размер листа растут, пересчёт при открытии; файл проходит проверку схемы.
Неизвестная колонка, список в ячейке, все значения пустые — ошибка, файл не тронут. Проверка после сбоя: такая же строка
выше — «не выполнено», после шага — «выполнено», две — «неясно». «Изменить»: только указанные ячейки (оформление
сохраняется, null очищает), формулу не заменяет, «не найдена» — свой выход, несколько строк — ошибка без изменений.
Таблица, открытая в Excel (`~$имя`), не меняется, временных файлов не остаётся. Новая книга со строкой названий; длинное
целое — текстом. .xls, не таблица и битый файл — понятная ошибка. CSV: Windows-1251 с «;», кавычками и переводом строки
в поле; дописанная строка — в той же кодировке, прежние байты не тронуты, дробная часть через запятую, «;» в значении —
в кавычках; UTF-8 с «,» без перевода строки в конце; апостроф перед «=», «@», «+» (но не перед «-5»); знак вне
кодировки — ошибка без записи; «Изменить» переписывает только свою строку, повтор с теми же значениями файл не трогает;
проверка отличает прежние значения от чужих; строка, сдвинувшаяся после подготовки, не меняется; новый CSV — UTF-8 с
BOM и «;»; значения списком и буквы колонок без названий. В движке: таблица аккаунтов перебирается циклом, каждому
ставится «готово» и строка в отчёт .xlsx; сбой после записи и «Проверить» — строка не дописана второй раз; 8 процессов
одновременно пишут в одну книгу — все строки на месте; неоднозначная строка — остановка с причиной, файл не тронут.
В приложении (`TableApiTests`): блоки и раздел в конструкторе, «Пример 15» дважды — в журнале 1, затем 2 строки. Замечания
проверки (`TableReviewTests`): длинные счета и номера с нулями впереди не совпадают с другими, «1.10» ≠ «1.1»; изменение
регистра и цифр записывается, а не считается «уже так»; перевод строки, число под форматом даты и число с порядком
сверяются как записанные; после сортировки проверка «Изменить» не говорит «выполнено»; пустое искомое значение —
ошибка; новая .xlsm — книга с макросами; повторяющиеся названия колонок — ошибка, «Имя (B)» и «Имя (2)» не путаются;
незакрытая кавычка — файл не меняется; изменение строки под «умной таблицей» её не растягивает; знаки вне XML — ошибка;
«_x000D_» читается знаком, «_x0041_» в тексте остаётся текстом; формула массива и защищённый лист — ошибка; «sep=,»;
даты до марта 1900 и длительность [ч]:мм:сс; CSV из латиницы без BOM — Кириллица в кодировке Windows (не на Windows — UTF-8).

подсказку про прокси; испорченный файл настроек прокси не приводит к подключению напрямую.

## Как запустить

```bash
dotnet test Pepa.slnx            # все тесты .NET (~1 минута)
cd ui && npm test                # модульные тесты интерфейса
cd ui && npm run build && dotnet build ../src/Pepa.Server && npm run e2e   # сквозная проверка (нужен Playwright)
```

В CI (`.github/workflows/build.yml`) на каждый push: на Windows — все тесты и сборка приложения (артефакт
`Pepa-win-x64`), на Linux — все тесты и сквозная проверка интерфейса со скриншотами (артефакт `e2e-screenshots`).

## Что проверяется только вручную (на Windows)

- Само окно WPF: запуск, WebView2, выбор папки, «открыть в проводнике», предупреждение при закрытии,
  активация уже открытого окна при повторном запуске. В контейнере разработки окно только компилируется.

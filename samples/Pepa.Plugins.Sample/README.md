# Пример расширения Pepa

Расширение добавляет в конструктор свои блоки. Это обычная сборка .NET (библиотека классов), в которой есть класс,
реализующий `Pepa.Core.Plugins.IPepaPlugin`.

## Как сделать своё

1. Создайте библиотеку классов .NET 10 и подключите `Pepa.Core` (проект или сборку из папки Pepa) — так, чтобы
   `Pepa.Core.dll` **не** копировался рядом с вашей сборкой (`Private="false"`): у расширения та же сборка, что у Pepa.
2. Реализуйте `IPepaPlugin`: в `Register` добавьте раздел палитры (`AddCategory`) и блоки (`AddNode`).
3. Каждый блок — `INodeExecutor` с описанием (`NodeTypeDescriptor`):
   - тип — со своим префиксом через точку (`моя-компания.отчёт`); префиксы встроенных блоков (`browser.`, `telegram.`,
     `file.` и т. п.) заняты;
   - `Effect` честно говорит, меняет ли блок что-то снаружи. Блок с внешним действием (`NodeEffect.External`) либо умеет
     проверить результат (`PrepareAsync` + `VerifyAsync`, `SupportsVerification = true`), либо после сбоя Pepa спросит
     пользователя — сама повторять не будет;
   - ошибки — через `NodeResult.Fail` (повторять можно или нет) и `NodeResult.Unknown` (неизвестно, выполнилось ли);
     неверные параметры — `NodeInputException`;
   - проверка результата отвечает «выполнено» только при полной уверенности; «не выполнено» — только если действия
     точно не было (Pepa тогда может повторить его); всё остальное — «неизвестно» (`Inconclusive`), и решает пользователь;
   - пути к файлам — через `registration.ResolveWorkspacePath(путь)`: те же проверки, что у встроенных блоков файлов.
   При загрузке Pepa проверяет описания: свой раздел палитры (существующие заменять нельзя), название и описание блока,
   непустые и неповторяющиеся id выходов и имена полей, варианты у полей-списков. Ошибка — расширение не загружается.
4. Соберите: `dotnet build -c Release`.

## Как поставить

Положите собранную сборку (и её собственные зависимости, если есть) в папку данных Pepa:
`%LOCALAPPDATA%\Pepa\plugins\<имя расширения>\` и перезапустите Pepa. Что загрузилось — «Настройки» → «Расширения»;
там же видна причина, если расширение не загрузилось (остальная Pepa при этом работает).

Расширение работает с правами Pepa — ставьте только те, которым доверяете.

В этом примере два блока: «Изменить регистр текста» (без внешних действий) и «Дописать строку в файл» (внешнее
действие с проверкой результата: строка не допишется дважды после сбоя).

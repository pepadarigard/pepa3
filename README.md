# Pepa — локальная платформа автоматизаций для Windows

Сценарии собираются из блоков в визуальном конструкторе и исполняются надёжным движком: каждое действие
записывается на диск до выполнения, после сбоя ничего не продолжается само, а действие с неизвестным итогом
не повторяется вслепую — Pepa сначала проверяет результат.

> Состояние: этапы 0–5 и часть этапа 6 (свои блоки-расширения). Работают конструктор, запуск, ожидания, повторы, обработка ошибок,
> история, восстановление после перезапуска, файловые действия, таблицы Excel и CSV, почта (ждать письмо с кодом), запросы к сайтам (HTTP), события (ожидание, отправка, сопоставление,
> конфликты, защита от повторов), ресурсы с очередью, запуск по расписанию и по событию, вызов сценария из
> сценария, перебор списков, браузер (Edge/Chrome), профили AdsPower и Telegram (свой аккаунт: отправить
> сообщение или файл, дождаться ответа, нажать кнопку бота, сохранить вложение), окна Windows (UI Automation), мышь и клавиатура, запись действий в браузере и в окнах Windows,
> отладка (пошаговый запуск, точки останова), группы блоков на схеме и ИИ-помощник (см. [docs/ROADMAP.md](docs/ROADMAP.md)).
> AdsPower, Telegram и окна Windows проверены на имитациях — что проверить на своём ПК и в каком порядке, описано в
> [docs/CHECKLIST.md](docs/CHECKLIST.md).

## Как запустить на Windows

**Готовая сборка.** Откройте вкладку **Actions** репозитория → последний успешный запуск «Сборка и тесты» →
внизу артефакт **Pepa-win-x64** → скачайте, распакуйте и запустите `Pepa.exe`. Установка .NET не нужна. Нужен
Microsoft Edge WebView2 Runtime — он есть в Windows 11 и обычно в Windows 10; если его нет, Pepa подскажет.

**Сборка самостоятельно** (нужны .NET 10 SDK и Node.js 22):

```powershell
powershell -ExecutionPolicy Bypass -File build\build.ps1
.\out\Pepa\Pepa.exe
```

Данные хранятся в `%LOCALAPPDATA%\Pepa` (база `pepa.db`, журналы `logs\`, резервные копии базы `backups\` — раз в
сутки и перед обновлением; восстановление описано в «Настройках» → «Резервные копии»). Завершённые процессы хранятся в
истории 90 дней (меняется в «Настройках»). Файловые действия работают только
внутри рабочей папки — по умолчанию `Документы\Pepa Workspace`, меняется в «Настройках».

## Первые шаги

1. При первом запуске появятся шестнадцать примеров. Откройте «Сценарии» → «Пример 1» → «Запустить».
2. На странице процесса видно, что происходит: шаги, журнал, переменные, схема с подсветкой пройденных блоков.
3. «Пример 3» ждёт 15 секунд: закройте Pepa во время ожидания и откройте снова — процесс будет приостановлен и
   продолжится только по вашей команде.
4. «Пример 5» занимает ресурс «профиль» и ждёт ответ: на странице «Выполнение» нажмите «Отправить событие»,
   укажите ключ — номер заказа из запуска (по умолчанию `A-100`) — и любой текст. Процесс сохранит ответ в файл.
5. У сценария можно включить автозапуск: «Сценарии» → «…» → «Автозапуск…» (по расписанию или по событию).
6. «Пример 7» открывает Edge и сохраняет заголовок страницы; «Пример 8» открывает профиль AdsPower (укажите его ID
   при запуске или выберите из списка в конструкторе), делает снимок и ждёт ответ-событие.
7. Telegram: «Интеграции» → Telegram → api_id и api_hash (выдаёт my.telegram.org → API development tools), телефон,
   затем код из Telegram. «Пример 9» пишет в указанный чат и ждёт ответ; «Пример 10» — то же вместе с профилем
   AdsPower и сайтом. Ответ, пришедший, пока Pepa была закрыта, процесс получит после запуска. Если Telegram
   недоступен в вашей сети, там же → «Прокси» → вставьте ссылку на прокси (tg://proxy…, tg://socks…, socks5://…),
   нажмите «Проверить» и «Сохранить и подключиться». Чтобы узнавать об остановившихся процессах, когда вас нет у
   компьютера: «Настройки» → «Уведомления» → сообщать в Telegram (в «Избранное»).
8. «Новый сценарий» → конструктор: перетаскивайте блоки слева, соединяйте выходы со входами, настраивайте справа.
   «Записать» превращает ваши действия в браузере или в окнах Windows в блоки, «Пошагово» запускает с паузой перед
   каждым блоком. В блоках окон Windows элемент можно выбрать из списка: «Выбрать элемент в окне».
9. ИИ-помощник (необязательно): «Настройки» → «ИИ-помощник» → ключ API Anthropic (console.anthropic.com), затем в
   конструкторе «ИИ-помощник» → опишите задачу словами → проверьте предложенные блоки → «Вставить в схему».
   Помощник ничего не запускает; его блоки проходят ту же проверку, что и ваши. Там же — «Изменить сценарий»
   (правка словами с показом изменений до применения) и «Объяснить сценарий».
10. Свои блоки (для разработчиков): расширение — сборка .NET в папке `%LOCALAPPDATA%\Pepa\plugins\<имя>\`; пример и
    инструкция — `samples/Pepa.Plugins.Sample`. Что загрузилось — «Настройки» → «Расширения».

## Без окна (разработка, браузер)

```bash
cd ui && npm ci && npm run build && cd ..
dotnet run --project src/Pepa.Server -- --data-dir ./.data --port 5180 --token dev
# открыть http://127.0.0.1:5180/#token=dev
```

Разработка интерфейса с горячей перезагрузкой: сервер как выше, затем `cd ui && npm run dev` и
`http://localhost:5173/#token=dev`.

## Структура

```
src/Pepa.Core               модель сценария, проверка, выражения, контракты блоков
src/Pepa.Engine             движок, процессы, восстановление, логические блоки
src/Pepa.Storage.Sqlite     хранилище
src/Pepa.Adapters.FileSystem  файловые действия
src/Pepa.Adapters.Tables    таблицы Excel (.xlsx) и CSV
src/Pepa.Adapters.Email     почта (IMAP): письма как события
src/Pepa.Adapters.Http      запросы к сайтам и API
src/Pepa.Adapters.Browser   браузер (Playwright) и AdsPower
src/Pepa.Adapters.Telegram  Telegram (пользовательский аккаунт, MTProto)
src/Pepa.Adapters.Desktop   блоки окон Windows, мыши и клавиатуры (за IDesktop)
src/Pepa.Adapters.Desktop.Windows  UI Automation (FlaUI) и SendInput — только Windows
src/Pepa.Assistant          ИИ-помощник конструктора (Claude API)
src/Pepa.Host               локальный API, настройки, примеры
src/Pepa.Server             запуск без окна
src/Pepa.Desktop            окно Windows (WPF + WebView2)
ui/                         интерфейс (React, TypeScript, React Flow)
tests/                      тесты
```

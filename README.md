# Pepa — локальная платформа автоматизаций для Windows

Сценарии собираются из блоков в визуальном конструкторе и исполняются надёжным движком: каждое действие
записывается на диск до выполнения, после сбоя ничего не продолжается само, а действие с неизвестным итогом
не повторяется вслепую — Pepa сначала проверяет результат.

> Состояние: первая рабочая версия (этапы 0–1). Работают конструктор, запуск, ожидания, повторы, обработка
> ошибок, история, восстановление после перезапуска и файловые действия. Браузер, AdsPower, Telegram, Windows-
> приложения, события и расписания — следующие этапы (см. [docs/ROADMAP.md](docs/ROADMAP.md)).

## Как запустить на Windows

**Готовая сборка.** Откройте вкладку **Actions** репозитория → последний успешный запуск «Сборка и тесты» →
внизу артефакт **Pepa-win-x64** → скачайте, распакуйте и запустите `Pepa.exe`. Установка .NET не нужна. Нужен
Microsoft Edge WebView2 Runtime — он есть в Windows 11 и обычно в Windows 10; если его нет, Pepa подскажет.

**Сборка самостоятельно** (нужны .NET 10 SDK и Node.js 22):

```powershell
powershell -ExecutionPolicy Bypass -File build\build.ps1
.\out\Pepa\Pepa.exe
```

Данные хранятся в `%LOCALAPPDATA%\Pepa` (база `pepa.db`, журналы `logs\`). Файловые действия работают только
внутри рабочей папки — по умолчанию `Документы\Pepa Workspace`, меняется в «Настройках».

## Первые шаги

1. При первом запуске появятся четыре примера. Откройте «Сценарии» → «Пример 1» → «Запустить».
2. На странице процесса видно, что происходит: шаги, журнал, переменные, схема с подсветкой пройденных блоков.
3. «Пример 3» ждёт 15 секунд: закройте Pepa во время ожидания и откройте снова — процесс будет приостановлен и
   продолжится только по вашей команде.
4. «Новый сценарий» → конструктор: перетаскивайте блоки слева, соединяйте выходы со входами, настраивайте справа.

## Без окна (разработка, браузер)

```bash
cd ui && npm ci && npm run build && cd ..
dotnet run --project src/Pepa.Server -- --data-dir ./.data --port 5180 --token dev
# открыть http://127.0.0.1:5180/#token=dev
```

Разработка интерфейса с горячей перезагрузкой: сервер как выше, затем `cd ui && npm run dev` и
`http://localhost:5173/#token=dev`.

## Структура

```
src/Pepa.Core               модель сценария, проверка, выражения, контракты блоков
src/Pepa.Engine             движок, процессы, восстановление, логические блоки
src/Pepa.Storage.Sqlite     хранилище
src/Pepa.Adapters.FileSystem  файловые действия
src/Pepa.Host               локальный API, настройки, примеры
src/Pepa.Server             запуск без окна
src/Pepa.Desktop            окно Windows (WPF + WebView2)
ui/                         интерфейс (React, TypeScript, React Flow)
tests/                      тесты
```
